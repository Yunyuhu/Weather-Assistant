關於這個作品
  1. 取得官方預報伺服器讀取中央氣象署公開的 36 小時縣市預報，整理成三個時段。
  2. 檢查欄位溫度、降雨機率、天氣描述都驗證過才送出，資料不完整就停止，不讓 AI 猜。
  3. 依資料回答把同一份預報和你的問題交給 OpenAI API，只回答預報支持的內容。

前端放在 GitHub Pages，API 部署在 Vercel，金鑰只存在伺服器。這裡不提供即時警報，數值以氣象署發布為準；問題送出後由 OpenAI 處理，本站不保存紀錄。
